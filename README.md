# FURST MEDIA .LIVE — site

Public website for **FURSTMEDIA LIVE LLC** (Pāhoa, Hawaiʻi): AI help for Puna/Hilo
small businesses, and KPNA internet radio.

- `index.html` — company home (holds the Organization / Person / WebSite JSON-LD)
- `ai-help/` — AI help service page
- `radio/` — KPNA station page
- `styles.css` — shared styles (palette matches the FURSTMEDIA call cards)
- `sitemap.xml`, `robots.txt`, `CNAME` — SEO + custom domain
- `og-image.png`, `icon-512.png`, `apple-touch-icon.png` — generated by `tools/make_images.py`

Published via GitHub Pages at https://furstmedia.live (DNS at GoDaddy).

When you change a page, bump its `<lastmod>` in `sitemap.xml`.
